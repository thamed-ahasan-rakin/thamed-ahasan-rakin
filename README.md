Featured Research Project
Bangla License Plate Detection and Deblurring
A team research project exploring a multi-stage workflow for oriented license-plate localization, geometric rectification, and image restoration.
- Detection: fine-tuned YOLOv8m-OBB to localize tilted or rotated Bangla license plates.
- Restoration: developed a modified DeblurGAN-style architecture with Line-Curve blocks combining horizontal, vertical, and deformable convolution branches.
- Dataset: developed and prepared a custom Bangla license-plate dataset for the experiments.
- Evaluation: compared restoration results using PSNR, SSIM, and MAE, alongside detection metrics for the OBB model.
Links: Research repository · Dataset on Roboflow

The project was conducted as a team. See the research repository for its methods, reported results, limitations, and implementation details. Character recognition/OCR is outside the implemented scope described in the thesis.
